# Build Containers

elementary-build-container is a repo for OCI (podman) containers used in various CI/CD from the elementaryOS deployement process. </br>

Theses container have tags matching elementaryOS releases (ex: `:tanit`)

They are made to be generic and minimal


## Available containers:


- `ghcr.io/elementary/mkosi:{RELEASE}`
- `ghcr.io/elementary/xorriso:{RELEASE}`
